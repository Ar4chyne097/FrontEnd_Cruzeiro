Este é um parágrafo. Vamos demonstrar neste exemplo diferentes tags do HTML5, para analisar como funcionam.

Esta é uma tag div. Ela é um bloco retângular onde podemos colocar texto, figuras, etc. Dentro vamos colocar esta tag span, de tipo inline que não quebra linha e não é tag de tipo bloco.
Esta é uma tag sextion, é uma tag de bloco introduzida no HTML5, considerada uma "tag semântica", como também as tags article, section, header, footer, figure...
Esta é uma tag article. Dentro vamos colocar algo em negrito, outro texto em itálico, outro texto sublinhado e um texto marcado.
